# 功能范围与实现原则

本目录定义 Clarkaitoy 的产品功能基线。所有功能文档和后续代码实现都必须以
[功能覆盖矩阵](feature-coverage.md) 为准。

## 实现范围

以下范围全部属于必须实现的内容：

- 基础层功能。
- 主流层功能。
- 差异化层功能。
- 市场调研中的 P0、P1、P2 功能。

优先级只决定实施顺序，不表示功能可以省略。任何功能可以按发行配置关闭，但代码
仓库、接口边界和测试基线仍然保留。

## 分层说明

| 层级 | 目标 |
| --- | --- |
| 基础层 | 保证设备可以启动、联网、对话、播放内容、执行家长控制和升级 |
| 主流层 | 补齐多轮对话、英语、内容运营、陪伴、诊断、远程消息和摄像头能力 |
| 差异化层 | 提供屏幕、触摸、4G、电池、动作、穿戴、视频陪伴和多设备能力 |

## 优先级说明

| 优先级 | 含义 |
| --- | --- |
| P0 | 首个可交付闭环必须完成，后续版本不得破坏 |
| P1 | 主流产品能力，在第一阶段稳定后必须完成 |
| P2 | 差异化产品能力，按硬件版本和产品节奏完成，但不得从规划中删除 |

## 仓库职责

| 仓库 | 主要职责 |
| --- | --- |
| `clarkaitoy-platform` | 家长端、管理端、平台服务、语音网关和共享契约 |
| `clarkaitoy-firmware` | ESP32-S3 设备端能力，所有功能均独立模块化 |
| `clarkaitoy-sub2api-fork` | 模型路由、供应商适配、配额、审计和儿童安全策略 |

完整功能映射见 [功能覆盖矩阵](feature-coverage.md)，仓库代码文档见
[仓库代码文档索引](../repositories/README.md)。
